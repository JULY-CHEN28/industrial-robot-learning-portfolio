# ZU5 模型与仿真假设

官方来源：<https://github.com/JAKARobotics/jaka_ros2>。
固定提交：`f6b28c6be93f289f101c6cc3907caf7804fb1a47`。

`assets/jaka_zu5.urdf`、`assets/meshes/*.STL`、`assets/package.xml` 从该提交原样提取。
逐文件 SHA256 记录于 `assets/source_manifest.json`。上游 description 包的许可证字段为
`TODO`，本地保留其原始声明，不为这些资产另行声明开源许可证；对外分发前需向来源确认。

`import_model.py` 可从本地 Git 对象数据库重建资产及 `assets/scene.xml`，无需 ROS 安装。
模型构建使用原始关节轴、原点、限位、质量、质心及完整惯量张量。
网格的碰撞采用 MuJoCo 凸包，所有相邻连杆对排除自碰撞，其余非相邻连杆与地面启用碰撞。
这不是经过碰撞分解或现场标定的精确模型。上游零姿态会有部分末端网格低于安装面，
因此本任务从经过碰撞检查的弯曲姿态启动，不使用全零关节姿态。

默认裸臂末端为 `Link6` 原点，无附加夹爪、工具质量或 TCP 偏置。
目标是无碰撞的小球标记，成功表示裸臂末端点距目标小于 25 mm 且无穿透接触；
未实现原 Kinova 项目中的实体目标球、表面间隙、桌面/夹具或质检任务。

第一轮任务每回合 8 秒，只出现一个固定目标。目标通过 HOME 周围有限关节范围的
无接触构型做 FK 生成，再过滤离初始末端至少 5 cm 且高度大于 15 cm 的点。
这保证目标存在一个对应的无接触构型，但不证明从任意初态有无碰撞路径。
该采样分布不等同于全工作空间，也不等同于 Kinova 旧任务分布。

控制为 2 ms 物理积分、32 ms 策略周期。动作是 HOME 加上 0.8 rad 倍率的六维绝对参考
位置；跟踪误差限制为 0.15 rad，参考速度 0.5 rad/s、参考加速度 1 rad/s²。
36 维观测依次为：关节偏离 HOME 6、关节速度 6、末端位置 3、目标相对位置乘 5 的 3、
上一动作 6、归一化参考位置 6、归一化参考速度 6。长度用米、角度用弧度。

PD 增益、阻尼、armature 与力矩限幅均为本次仿真调试参数，并非官方真实控制器规格。
偏置补偿与参考速度前馈共享力矩限幅，未实现真实控制器的辨识、网络延迟或固件行为。
原 URDF 中惯量与 effort 数值尚未向厂商/现场核实，未把 effort 字段当作真实力矩规格。
目前保留官方惯量，未擅自调整。策略加载时检查配置与场景 SHA256，拒绝不匹配模型。

现场工具、零位及控制器响应补齐后，应更新环境并重新评估/训练。第一轮结果只证明
当前假设下的仿真训练闭环，不能作为可直接上真机的结论。

## 连续任务扩展

`continuous_zu5.py` 在同一控制和观测定义上扩展时域，每个目标固定 4 秒，
序列中不重置机械臂。独立采样器先生成整条目标序列，除首轮目标约束外，还要求
相邻目标至少相距 5 cm。该排除条件改变了目标序列分布，应与原独立回合任务区分报告。
切换时仅更新目标位置和对应标记；控制状态、上一动作及仿真时间保留。
控制边界的奖励和成绩属于刚执行完的目标，下一次观测包含新目标；序列末尾不生成额外目标。
这没有改变观测/动作/控制器的策略接口，因此沿用原 300000 步权重。

## 扰动模型边界

`robustness_zu5.py` 只做敏感性评估，不修改/训练策略权重。噪声是独立、零均值高斯噪声，
参数为标准差。带噪 TCP 同时用于末端位置和相对目标位置通道，防止同一位置出现
相互矛盾的两个观测。目标 x 偏差只影响策略输入，真实目标与评分不变。

观测延迟作用于关节位置/速度与 TCP 传感数据，目标指令和本地控制历史保持当前值。
指令延迟作用于 PPO 原始动作，位于本地参考轨迹生成器之前；启动时队列填充当前位置
保持动作，跨目标保留队列、跨序列清空队列。它不等于 SDK 关节参考发点链路的全部延迟，
未模拟随机抖动、丢包、乱序、控制器队列或电脑调度。低层控制依然访问理想真实状态。

质量偏差按所有连杆质量和惯量的相同比例缩放，补偿使用独立名义模型，
不因仿真获得真实参数而自动修正；它不代表某个夹爪的质量/质心或碰撞几何。
增益偏差同时修改位置反馈与对应位置项，阻尼与速度前馈按同一阻尼配置变化。
补偿缩放条件只缩放动力学偏置项，速度前馈和共享力矩上限仍保留。
这些是抽象误差条件，不能据此给出真实设备允许的延迟、负载或安全工作范围。
