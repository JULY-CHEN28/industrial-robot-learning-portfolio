# 实验协议与结果

## Isaac Lab

任务 `Gen3-Reach-v0`；原Isaac Lab 2.1 / Isaac Sim 4.5；确定性策略、关闭观测噪声。每模型两组测试种子510000、610000，每组64环境、24秒。按固定时长规则排除每组64个重置边界短片段，保留320个窗口；两种策略共用640个配对窗口，不是1280个独立抽样目标。

位置到达要求误差小于5 cm；完整位姿还要求旋转误差小于0.2 rad；保持要求连续16个采样状态达标，首末相隔0.5秒。阈值为本项目诊断定义，不是上游公布的验收标准。

| 指标 | 作者公开模型 | 本地 Seed 44 |
| --- | ---: | ---: |
| 位置到达 | 508/640（79.38%） | 544/640（85.00%） |
| 位置保持 | 488/640（76.25%） | 512/640（80.00%） |
| 完整位姿到达 | 180/640（28.12%） | 227/640（35.47%） |
| 完整位姿保持 | 173/640（27.03%） | 206/640（32.19%） |
| 全过程平均位置误差 | 7.322 cm | 5.736 cm |
| 窗口结束平均位置误差 | 5.269 cm | 3.311 cm |
| 全过程平均姿态误差 | 32.574° | 32.556° |

三次独立训练分别98,304,000环境步；合计294,912,000步不代表单个模型训练量。Seed 44由此前评估选定；现有两组测试不足以证明算法普遍优越，也未进行统计显著性推断。

数据：`results/isaaclab/comparison.json`；逐窗口与原始数组：`results/isaaclab/paired/`。作者模型SHA256及本地模型SHA256保留在汇总中。仓库不分发作者权重，也未包含本地Seed 44权重；原始数组可用于重新统计，不等于能重新执行两模型rollout。

## Kinova MuJoCo

选定checkpoint累计6,850,000步。目标每4秒切换；位置误差小于25 mm、机械臂距球表面至少5 mm、当前无障碍物接触计为安全到达；连续满足至少0.5秒计为安全停留。

两组新种子各300个目标，合计600个：安全到达592/600，安全停留579/600。长序列每条60秒，中途不重置机械臂。目标与Isaac Lab完整位姿任务不同；运动途中仍有少量接触，不能称为全程无碰撞。

数据：`results/kinova_mujoco/`。平均回合结束误差不等于每个目标窗口的结束误差；报告分开保存。

## JAKA MuJoCo

裸臂Link6原点的位置任务，局部采样空间、无碰撞目标标记，无完整姿态与实体目标间隙要求。位置误差小于25 mm且无穿透接触计为到达；连续16个32 ms控制步（0.512秒）计为停留。

连续测试为20条60秒序列和5条300秒序列，序列内部不重置，合计675个目标；全部曾到达并停留。窗口结束平均误差约2.98 mm，合计45分钟模拟时间。该结果不能解释为全工作空间成功率或真机控制精度。

扰动初筛14种条件×30目标，复核5种条件×60目标，共720个“目标×条件”窗口。不同条件复用目标，不能称为720个独立抽样目标。名义、96 ms指令延迟、30 mm目标偏差、轻度组合、强组合的复核停留数分别为60、60、16、60、13，分母均为60。

数据：`results/jaka_mujoco/`。仿真低层参考控制仍可访问理想状态；扰动结果不能用于规定真实设备的允许时延或参数范围。

## 数据整理

JSON仅替换本机和服务器工作目录，并重新排版；数值、种子和模型哈希不变。源代码及文档统一为LF换行，NPZ原始数组按字节保留。原始来源、变换方式与原文件SHA256见 `results/provenance.json`；发布文件哈希见 `SHA256SUMS.json`。
